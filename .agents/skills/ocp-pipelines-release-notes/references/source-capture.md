## Source Boundaries

This skill covers only the OpenShift Pipelines 1.22 release notes. It
documents what changed, what is new, what is deprecated, what is removed, what
is broken, and what is known to be broken across the 1.22.x sub-releases.

This skill does NOT cover:

- OpenShift Pipelines installation, configuration, or administration
- Tekton CRD authoring (Pipeline, Task, PipelineRun, TaskRun)
- Pipelines as Code setup, Repository CR configuration, or webhook setup
- General CI/CD pipeline design patterns
- OpenShift Pipelines versions other than 1.22.x
- OpenShift Builds, OpenShift GitOps, or Jenkins
