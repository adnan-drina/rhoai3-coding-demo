## Source Boundaries

This skill covers only the troubleshooting aspects of Red Hat OpenShift
Lightspeed 1.0. It documents common error messages, API authentication
failures, prompt and response token issues, conversation history problems,
reasoning model delineator output, OperatorHub visibility, and Google Vertex AI
configuration validation errors.

This skill does NOT cover:

- OpenShift Lightspeed concepts, architecture, or feature overview
- Operator installation or upgrade procedures
- OLSConfig CR authoring beyond troubleshooting validation errors
- Day-2 operations, scaling, or monitoring
- OpenShift Lightspeed versions other than 1.0
- Must-gather data collection (not present in the 1.0 troubleshoot guide)
- LLM provider setup beyond Google Vertex AI validation errors
