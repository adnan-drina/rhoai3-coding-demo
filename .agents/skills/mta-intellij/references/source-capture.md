## Source Boundaries

This skill covers the IntelliJ IDEA Plugin Guide only. It provides IDE-based
analysis workflows for IntelliJ IDEA users. It does not cover:

- MTA CLI analysis workflows (separate CLI Guide)
- MTA web UI workflows (separate User Interface Guide)
- VS Code extension workflows (separate VS Code Extension Guide)
- Custom rule authoring (separate Rules Guide, see mta-rules skill)
- AI-assisted code resolution via Developer Lightspeed
- Server-side MTA deployment or operator configuration
- Maven or Gradle plugin integration
