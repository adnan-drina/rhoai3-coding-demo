## Source Boundaries

- Product configuration truth: official Quick Start Guide above.
- Narrative and examples: Red Hat articles/blogs and rh-brain.
- Verification: Hybrid Cloud Console access and IDE extension behavior.
- Not authoritative: upstream Trustify community docs unless explicitly labeled
  as supplemental background.
- Self-hosted deployment procedures are out of scope for this skill; use
  `tpa-deployment` instead.
- Administration and advanced configuration are out of scope; use `tpa-admin`.
- Release-specific changes and known issues are out of scope; use
  `tpa-release-notes`.
