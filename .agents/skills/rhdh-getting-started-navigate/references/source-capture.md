## Source Boundaries

This skill covers the "Navigate Red Hat Developer Hub on your first day" guide
only. It provides:

- Developer onboarding and first-day workflow
- Interface navigation (global header, sidebar)
- Software Catalog browsing and filtering
- Software Templates usage and import
- TechDocs search and navigation
- API browser and interactive testing
- Global search and filtering
- Developer Lightspeed for RHDH (AI assistant, notebooks)
- Extensions marketplace
- Interface customization and starred items

It does not cover:

- Operator installation or Backstage CR configuration (separate guide)
- External service preparation (separate guide)
- Authentication and RBAC setup (separate guide)
- Plugin development
- Advanced catalog-info.yaml authoring
- Platform administration beyond user-facing settings
