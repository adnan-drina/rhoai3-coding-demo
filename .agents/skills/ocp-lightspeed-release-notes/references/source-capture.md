## Source Boundaries

This skill covers only the OpenShift Lightspeed 1.0 release notes (which
includes 1.0, 1.1, and 1.1.1 sub-releases as documented under the 1.0
product version). It documents what changed, what is new, what security issues
were fixed, what is known to be broken, and what Technology Preview features
are available.

This skill does NOT cover:

- OpenShift Lightspeed concepts, architecture, or product overview
- OpenShift Lightspeed installation or Operator lifecycle
- OLSConfig custom resource configuration or provider setup
- Day-2 operations, scaling, or administration
- Troubleshooting or diagnostics
- OpenShift Lightspeed versions outside the 1.0 product documentation
