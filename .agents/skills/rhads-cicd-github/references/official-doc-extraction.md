# Official Doc Extraction

Use this extraction to keep GitHub Actions CI/CD integration content grounded
in official RHADS-SSC 1.9 sources.

## Product Overview

Red Hat Advanced Developer Suite - software supply chain (RHADS-SSC) integrates
with GitHub Actions to perform vulnerability scanning, image signing, and
attestation generation. Pipelines require secrets configured as GitHub
repository secrets and variables.

## UI Configuration

### Adding Secrets

On the Actions secrets and variables page, Secrets tab:

1. Select New repository secret.
2. Enter the Name and Secret values.
3. Select Add secret.

### Adding Variables

On the Actions secrets and variables page, Variables tab:

1. Select New repository variable.
2. Enter the Name and Value.
3. Select Add variable.

## Secrets (Repository Secrets)

### Image Registry and GitOps Secrets

| Variable | Description |
|----------|-------------|
| `IMAGE_REGISTRY_PASSWORD` | Password for accessing your container image registry |
| `GITOPS_AUTH_PASSWORD` | Token the system uses to update the GitOps repository for newly built images |

### ACS and SBOM Secrets

| Variable | Description |
|----------|-------------|
| `ROX_API_TOKEN` | API token for accessing the ROX server |
| `COSIGN_SECRET_PASSWORD` | Password for Cosign signing key |
| `COSIGN_SECRET_KEY` | Private key for Cosign |
| `TRUSTIFICATION_OIDC_CLIENT_SECRET` | Client secret for Trustification Bombastic API OIDC auth |

All credentials are already Base64-encoded from `private.env` and do not
require additional encoding.

## Variables (Repository Variables)

### Image Registry Variable

| Variable | Description |
|----------|-------------|
| `IMAGE_REGISTRY_USER` | Username for accessing your container image registry |

### ACS and SBOM Variables

| Variable | Description |
|----------|-------------|
| `ROX_CENTRAL_ENDPOINT` | Endpoint for the ROX Central server |
| `COSIGN_PUBLIC_KEY` | Public key for Cosign |
| `TRUSTIFICATION_BOMBASTIC_API_URL` | URL for Trustification Bombastic API (SBOM) |
| `TRUSTIFICATION_OIDC_ISSUER_URL` | OIDC issuer URL for Trustification auth |
| `TRUSTIFICATION_OIDC_CLIENT_ID` | Client ID for Trustification OIDC auth |
| `TRUSTIFICATION_SUPPORTED_CYCLONEDX_VERSION` | CycloneDX SBOM version generated by the system |

### Optional Rekor and TUF Variables

Set these if CI provider runners do not run on the same cluster as the
RHADS-SSC instance:

| Variable | Description |
|----------|-------------|
| `REKOR_HOST` | URL of your Rekor server |
| `TUF_MIRROR` | URL of your TUF service |

## CLI Configuration

### env_vars.sh

Export all credentials in a shell file:

```bash
export GITOPS_AUTH_PASSWORD="your_github_token_here"
export IMAGE_REGISTRY_USER="your_registry_username_here"
export IMAGE_REGISTRY_PASSWORD="your_registry_password_here"
export QUAY_IO_CREDS_USR="your_quay_username_here"
export QUAY_IO_CREDS_PSW="your_quay_password_here"
export ROX_CENTRAL_ENDPOINT="your_rox_central_endpoint_here"
export ROX_API_TOKEN="your_rox_api_token_here"
export COSIGN_SECRET_PASSWORD="your_cosign_secret_password_here"
export COSIGN_SECRET_KEY="your_cosign_secret_key_here"
export COSIGN_PUBLIC_KEY="your_cosign_public_key_here"
export TRUSTIFICATION_BOMBASTIC_API_URL="your_bombastic_api_url_here"
export TRUSTIFICATION_OIDC_ISSUER_URL="your_oidc_issuer_url_here"
export TRUSTIFICATION_OIDC_CLIENT_ID="your_oidc_client_id_here"
export TRUSTIFICATION_OIDC_CLIENT_SECRET="your_oidc_client_secret_here"
export TRUSTIFICATION_SUPPORTED_CYCLONEDX_VERSION="your_version_here"
```

### ghub-set-vars Script

The script uses `gh variable set` and `gh secret set` to configure all
repository variables and secrets. It accepts an `OWNER/REPO` argument or a
full `https://github.com/OWNER/REPO` URL.

Supported image registries: Quay.io, JFrog Artifactory, Sonatype Nexus.

```bash
source env_vars.sh
chmod +x ghub-set-vars
./ghub-set-vars your_repository_name
```
