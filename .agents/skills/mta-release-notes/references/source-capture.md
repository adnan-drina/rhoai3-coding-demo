## Source Boundaries

This skill covers only the MTA 8.2 release notes (covering 8.0.0, 8.0.1, and
8.2.0). It documents what changed, what is new, what is fixed, what is known
to be broken, and what is deprecated or removed.

This skill does NOT cover:

- MTA installation, deployment, or Operator setup procedures
- MTA CLI or UI usage workflows
- Developer Lightspeed configuration or AI-assisted migration details
- MTA versions prior to 8.0
- Migration rules authoring or custom rule development
- Red Hat build of Keycloak administration beyond MTA RBAC
