## Source Boundaries

This source is authoritative for software development workflows in RHDH 1.10,
including Bulk Import (Technology Preview), Software Catalog management, and
Software Template usage.

It does **not** cover:
- TechDocs documentation lifecycle (separate guide)
- Adoption Insights analytics (separate guide)
- Plugin installation and configuration (separate guide)
- RBAC policy management (separate guide)
- Authentication provider setup (separate guide)
