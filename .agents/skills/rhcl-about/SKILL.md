# Connectivity Link: what it is here

Thin skill: repo decisions here, product concepts in the linked Connectivity
Link 1.4 sections. The version lives in `.agents/references/red-hat-doc-map.yaml`
(`products.rhcl.docs_version`).

## When to use

- Explaining the MaaS trust boundary: who authenticates and meters a model call.
- Deciding whether a need belongs to Connectivity Link, the MaaS controller, or
  the OpenShift Gateway API.

## Repo decisions

| Decision | Where in Git | Official section |
|---|---|---|
| Connectivity Link exists only as the MaaS policy layer (API-key auth and token limits on `maas-default-gateway`) | `gitops/stages/040-governed-models-as-a-service/maas-operators/README.md` | [About Connectivity Link][about] |
| One `Kuadrant` instance in `kuadrant-system`; the operator creates Limitador; Authorino is declared with a TLS listener | `gitops/stages/040-governed-models-as-a-service/gateway-governance/governance/` | [Install from the CLI][install-cli] |
| The Gateway uses the OpenShift Gateway API controller (class `data-science-gateway-class`), not a separate Istio control plane | `gitops/stages/040-governed-models-as-a-service/gateway-governance/gateway/` | [Required platforms and components][install-req] |
| Policies are generated by the OpenShift AI MaaS controller, not written by hand (`AuthPolicy maas-gateway-auth`, `TokenRateLimitPolicy` objects) | not in Git; see the 040 gateway-governance README | see `rhoai-maas-governance` |
| Not used: DNSPolicy, TLSPolicy, PlanPolicy, CoreDNS, multicluster Redis, the MCP gateway, the API-management console plugin | — | [Deploy Connectivity Link][deploy] |

## Pitfalls

- Older skill text and Stage 220 notes described a 1.3.4 pin. That posture is
  retired; Stage 040 runs 1.4.x (qualified minimum 1.4.3). Use `rhcl-update`.
- Supported configurations change per minor; read them from the
  [supported configurations][configs] section, not from memory. For 1.4 the
  docs list OpenShift 4.19–4.22, Service Mesh 3.3 or 3.4 when used, and
  cert-manager 1.19 for TLS policies.
