# Official Doc Extraction

Use this extraction to keep Jenkins CI/CD integration content grounded in
official RHADS-SSC 1.9 sources.

## Product Overview

Red Hat Advanced Developer Suite - software supply chain (RHADS-SSC) integrates
with Jenkins to perform vulnerability scanning, image signing, and attestation
generation. Jenkins requires credentials and environment variables configured
through its management interface.

## Setup Sequence

| Action | When to complete |
|--------|------------------|
| Adding secrets to Jenkins | Before using secure software templates to create an application |
| Adding application to Jenkins | After creating the application and source repositories |

## Automated Setup

The `ci-set-org-vars.sh` script from the `tssc-cli` image creates required
Jenkins credentials and environment variables:

```bash
bash-5.1$ ./scripts/ci-set-org-vars.sh -b jenkins
```

## Credentials (Secrets)

### Image Registry and GitOps

| Credential | Description |
|------------|-------------|
| `QUAY_IO_CREDS` | Username and password for accessing your Quay.io repository (default, uncommented in Jenkinsfiles) |
| `ARTIFACTORY_IO_CREDS` | Username and password for accessing your JFrog Artifactory repository |
| `NEXUS_IO_CREDS` | Username and password for accessing your Sonatype Nexus repository |
| `GITOPS_AUTH_PASSWORD` | Token the system uses to update the GitOps repository for newly built images |

To use JFrog Artifactory or Sonatype Nexus instead of Quay, uncomment the
corresponding variable lines in both Jenkinsfiles in the gitops-template and
source-repo folders of your cloned tssc-sample-templates GitHub repository.

### ACS and SBOM Secrets

| Credential | Description |
|------------|-------------|
| `ROX_API_TOKEN` | API token for accessing the ROX server |
| `COSIGN_SECRET_PASSWORD` | Password for Cosign signing key |
| `COSIGN_SECRET_KEY` | Private key for Cosign |
| `TRUSTIFICATION_OIDC_CLIENT_SECRET` | Client secret for Trustification Bombastic API OIDC auth |

All credentials are already Base64-encoded from `private.env` and do not
require additional encoding.

## Environment Variables

Set via Manage Jenkins > System > Global properties > Environment variables.

### GitOps Variable

| Variable | Description |
|----------|-------------|
| `GITOPS_AUTH_USERNAME` | (Optional) Required for Jenkins to work with GitLab |

### ACS and SBOM Variables

| Variable | Description |
|----------|-------------|
| `ROX_CENTRAL_ENDPOINT` | Endpoint for the ROX Central server |
| `COSIGN_PUBLIC_KEY` | Public key for Cosign |
| `TRUSTIFICATION_BOMBASTIC_API_URL` | URL for Trustification Bombastic API (SBOM) |
| `TRUSTIFICATION_OIDC_ISSUER_URL` | OIDC issuer URL for Trustification auth |
| `TRUSTIFICATION_OIDC_CLIENT_ID` | Client ID for Trustification OIDC auth |
| `TRUSTIFICATION_SUPPORTED_CYCLONEDX_VERSION` | CycloneDX SBOM version generated by the system |

### Optional Rekor and TUF Variables

Set these if Jenkins doesn't run on a local OpenShift instance and Rekor/TUF
services are on different clusters. Also uncomment lines with Rekor and TUF
variables in the Jenkinsfile in your cloned tssc-sample-templates repository.

| Variable | Description |
|----------|-------------|
| `REKOR_HOST` | URL of your Rekor server |
| `TUF_MIRROR` | URL of your TUF service |

## Adding Applications to Jenkins

### Pipeline Project Creation

1. Enter a name for the pipeline job; the name must match the application name.
2. Select Pipeline project type.
3. If using a different pipeline name, update `jenkins.io/job-full-name` in
   `catalog-info.yaml` in the application source repository.

### Repository Configuration

1. From RHDH Catalog, select the application.
2. Go to Overview > View Source to get the repository URL.
3. Enter the repository URL in the Pipeline configuration.

### Build and Verify

1. Select Build Now to start the pipeline.
2. In Stage View, select Pipeline Overview to visualize the run.
3. Select Pipeline Console for live logs of each stage.

## RHDH Integration Verification

After integration, verify pipeline visibility in Red Hat Developer Hub:

- **CI tab**: view Jenkins project, rerun jobs, view history
- **CD tab**: view commit messages, author names, ArgoCD/GitOps deployment
  history
- **Catalog > Kind: Resource**: view Jenkins GitOps jobs
- **Topology tab**: visualize application deployment in the dev namespace

## Verification

Rerun the latest pipeline run. If credentials and variables are correctly
applied, the pipeline completes and ACS scanning, SBOM generation, and image
signing display expected results.
