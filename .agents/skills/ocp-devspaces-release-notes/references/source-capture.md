## Source Boundaries

This skill covers only the OpenShift Dev Spaces 3.28 release notes. It
documents what changed, what is new, what is fixed, and what is known to be
broken across the 3.28.x sub-releases.

This skill does NOT cover:

- OpenShift Dev Spaces installation, configuration, or administration
- CheCluster CR configuration or DevWorkspace Operator administration
- User guide workflows (workspace creation, devfile authoring, IDE usage)
- Dev Spaces concepts, architecture, or product positioning
- OpenShift Dev Spaces versions other than 3.28.x
- OpenShift Pipelines, OpenShift GitOps, or other platform operators
