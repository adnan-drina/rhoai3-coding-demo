## Source Boundaries

This skill covers only MTA 8.2 installation procedures. It documents how to
install the MTA Operator, create MTA instances, install the CLI, and configure
persistent storage and authentication.

This skill does NOT cover:

- Running analyses or assessments (use mta-cli/mta-ui skills)
- Developer Lightspeed configuration or AI-assisted features
- Custom rules authoring or migration rule development
- MTA release notes or version history
- MTA versions prior to 8.0
- Application portfolio management or assessment questionnaires
