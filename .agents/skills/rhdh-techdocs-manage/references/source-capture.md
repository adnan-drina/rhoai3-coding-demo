## Source Boundaries

This source is authoritative for the TechDocs documentation lifecycle in
RHDH 1.10 — adding, importing, searching, viewing, editing, embedding video,
and automating builds via GitHub Actions.

It does **not** cover:
- Software Catalog or Bulk Import workflows (separate guide)
- Adoption Insights analytics (separate guide)
- TechDocs plugin installation and administrator configuration (separate guide)
- AWS S3 bucket creation or IAM policy setup (AWS documentation)
- Authentication provider setup (separate guide)
