## Source Boundaries

This skill captures:

- Overview of Developer Lightspeed for MTA concepts (RAG, Solution Server, Agent AI)
- Supported LLM providers and model examples
- Technology Preview support posture
- Prerequisites (MTA Operator 8.0.0, LLM API key, Java 17+, Maven 3.9.9+)
- Persistent volume requirements (5 Gi RWO for Solution Server)
- Workflow options (Agent AI without proxy, LLM proxy with/without Solution Server)
- LLM API key Secret creation (per provider)
- Tackle CR configuration for LLM proxy and Solution Server
- provider-settings.yaml structure for all supported providers
- VS Code extension GenAI settings
- Profile configuration for AI-assisted analysis
- Code resolution workflows (Solution Server mode, Agent AI mode)
- Data privacy and self-managed model hosting guidance
- Debugging and log archival

This skill does not capture:

- MTA Operator installation (separate guide)
- CLI-only analysis without AI features (separate guide)
- Web UI analysis workflows (separate guide)
- VS Code extension non-AI features (separate guide)
- IntelliJ IDEA plugin workflows (separate guide)
- Custom rule authoring (separate guide)
- MTA Hub administration (separate guide)
