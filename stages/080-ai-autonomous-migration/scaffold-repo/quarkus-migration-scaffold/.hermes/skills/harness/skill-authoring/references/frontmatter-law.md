# Frontmatter law (R-SK.2)

**Official:** https://hermes-agent.nousresearch.com/docs/user-guide/features/skills
§SKILL.md Format + published worked example (one-three-one-rule).

| Field | Rule |
|-------|------|
| `name` | = leaf directory name |
| `description` | ≤60 chars, imperative |
| `version` | semver; bump on every content change |
| `author` | required |
| `license` | required (demo redistribution) |
| `platforms` | optional list |
| `metadata.hermes.tags` | required |
| `metadata.hermes.category` | required; must equal parent category dir when categorized |
