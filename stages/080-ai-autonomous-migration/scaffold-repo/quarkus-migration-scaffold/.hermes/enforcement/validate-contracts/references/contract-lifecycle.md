# Contract lifecycle (GR1 / GRT)

**Status:** binding

Active binding prose lives next to its lint under `.hermes/**/references/`.
Retired, superseded, or obsolete prose moves to `tmp/governance-retired/`
(demo-repo attic), not an in-scaffold `governance/` folder.

Any markdown under `.hermes/**/references/` whose Status line matches
`retired|superseded|obsolete` fails `check-contract-lifecycle.py`.
